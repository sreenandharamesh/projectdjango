# 📝 Django Blogging Website

A simple blogging platform built with **Django** that allows users to **Create**, **Read**, **Update**, and **Delete** blog posts.  
It uses **XAMPP (MySQL)** as the database backend and provides a minimal, clean UI for managing blog content.

---

## 🚀 Features

- 🖊️ Create new blog posts
- 📖 View all published blogs
- 📝 Edit existing posts
- ❌ Delete posts
- 🗃️ MySQL database integration using XAMPP

---

## 🛠️ Tech Stack

- 🌐 **Backend**: Django (Python)
- 🗄️ **Database**: MySQL (via XAMPP)
- 🎨 **Frontend**: HTML, CSS, Bootstrap (optional)
